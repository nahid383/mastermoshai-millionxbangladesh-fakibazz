🌟 About The Project

Education should not be one-size-fits-all.

Every student has a different learning speed, different strengths, different weaknesses, and different ways of understanding concepts.

Master Moshai is built around this idea.

It combines modern web technologies with AI to create a personalized digital learning companion that can help students understand concepts, practice problems, receive guidance, and improve their learning journey.

🎯 Our Mission

«Make quality education more personalized, accessible, and engaging for every learner.»

🚀 Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

Check your versions:

node --version
npm --version
git --version

1️⃣ Clone the Repository

git clone https://github.com/nahid383/mastermoshai-millionxbangladesh-fakibazz.git

2️⃣ Enter the Project

cd mastermoshai-millionxbangladesh-fakibazz

3️⃣ Install Dependencies

npm install

4️⃣ Start Development Server

npm run dev

The development server will start locally.

---

🔐 Environment Variables

Create a ".env" file in the root directory.

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key

«⚠️ Never commit secret keys or private credentials to GitHub.»

---

📦 Build for Production

npm run build

To preview the production build:

npm run preview
